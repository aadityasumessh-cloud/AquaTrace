# 💧 Smart Water Governance Dashboard

A data-driven dashboard designed to monitor, analyze, and optimize water usage across hostels and rooms. This project helps improve water governance by providing clear insights into consumption patterns and enabling efficient resource management.

---

## 📌 Overview

Water management is a critical challenge in institutional environments. This project provides an interactive dashboard that allows users to track water usage at both hostel and room levels. It helps identify inefficiencies, unusual consumption patterns, and supports sustainable decision-making.

---

## 🚀 Features

- 📊 Interactive dashboard for real-time visualization  
- 🏢 Hostel-wise and room-wise water usage tracking  
- 🎯 Dropdown filters for dynamic selection  
- 📈 Graphs with proper headings and spacing  
- 🧭 Gauge indicators for quick insights  
- ✨ Smooth UI with hover effects  
- ⚡ Dashboard auto-launch on running the script
